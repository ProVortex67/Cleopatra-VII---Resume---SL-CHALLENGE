# Cleopatra VII — Executive Resume

A premium, responsive executive-profile website for the **SL Challenge**, reframing Cleopatra VII as a modern CEO-level leadership case study.

## Live site

https://provortex67.github.io/Cleopatra-VII---Resume---SL-CHALLENGE/

## Challenge description

Build a compelling executive resume / portfolio experience for Cleopatra VII that translates her historical leadership into a contemporary professional narrative. The experience communicates her profile, leadership style, achievements, capabilities, challenges, and a modern CEO assessment through a polished, distinctive and accessible interactive experience.

## Design direction

- Egyptian-inspired editorial art direction
- Obsidian / charcoal foundation with restrained antique-gold accents
- Cormorant Garamond editorial display type paired with DM Sans UI typography
- Executive-dossier information architecture
- Responsive mobile-first layout
- Scroll progress, reveal transitions, hover states and interactive assessment
- Reduced-motion support

## Included

- Executive profile and hero metrics
- Stylized Cleopatra portrait built in CSS
- Leadership style and principles
- Track-record timeline
- Core capabilities matrix
- Leadership challenges
- Interactive modern CEO assessment
- Responsive navigation and mobile layout
- Keyboard-friendly semantic controls
- `prefers-reduced-motion` support

## Tech stack

- React
- TypeScript
- Vite
- Lucide React
- CSS with responsive media queries and native motion preferences

## Setup

```bash
npm install
npm run dev
```

### Production build

```bash
npm run build
npm run preview
```

## GitHub Pages deployment

Deployment is automated with GitHub Actions. Every push to `main` builds the Vite production bundle and publishes `dist/` to GitHub Pages.

If Pages has not been enabled, open **Repository Settings → Pages** and set the source to **GitHub Actions**.

## Content note

This is an executive interpretation of Cleopatra VII's historical career. The modern CEO assessment is intentionally presented as a contemporary leadership lens rather than a substitute for primary-source scholarship.
